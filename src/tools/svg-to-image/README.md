# SVG 图像转换与可视化编辑器 (v2.0)

## 📋 功能概述

SVG 图像转换与可视化编辑器是一个专业级纯前端 SVG 工具箱，集成了现代代码编辑器、交互式预览画布与高清超采样导出能力，支持将 SVG 实时转换输出为 PNG、JPG、WEBP 格式或保存源码。

---

## 🎯 核心功能与亮点

### 1. 专业级代码编辑器 (基于 CodeMirror 6)
- **语法高亮与行号**: 针对 XML/SVG 结构语法高亮显示，支持代码折叠与自动换行。
- **深浅色主题自适应**: 自动根据系统与应用深浅模式切换编辑器高亮配色。
- **实用辅助工具**:
  - **一键格式化 (Beautify)**: 自动对齐标签层级与缩进。
  - **一键压缩 (Minify)**: 去除注释与冗余空格。
  - **快速示例库**: 预置科技指南针、创意调色盘、几何徽章等高质量 SVG。
  - **一键复制与本地文件导入**: 支持直接读取本地 `.svg` 文件。
- **实时语法校验**: 毫秒级检测未闭合标签或语法解析错误，并提供友好的提示指示。

### 2. 空间最大化与灵活布局
- **可拖拽调整比例分栏 (Splitter)**: 鼠标平滑拖拽分割条自由调整代码与预览区域宽度/高度占比，双击可快速 50% 复位。
- **左右 / 上下分栏一键切换**: 自由适配横屏桌面大显示器与竖屏窗口。
- **沉浸工作台模式 (Workbench Mode)**: 支持一键将工作台铺满整个视口，提供全屏级 IDE 工作体验。

### 3. 交互式预览画布
- **平移与缩放 (Pan & Zoom)**: 鼠标滚轮平滑缩放 (10% ~ 1000%)，按住鼠标拖拽平移画布。
- **视口控制胶囊**: 放大、缩小、1:1 像素复位、自适应居中适配窗口。
- **画布背景切换**: 支持透明棋盘格、纯白底、纯黑底及自定义拾色器背景。
- **元数据信息徽章**: 实时显示 SVG 的 `Width`、`Height`、`ViewBox` 及源码体积。

### 4. 高清超采样位图导出
- **多倍率渲染**: 支持 `1x` (标准)、`2x` (高清 Retina)、`3x` (超清)、`4x` (4K 矢量超采样) 或自定义输出像素宽高。
- **多格式支持**:
  - `PNG`: 无损透明通道。
  - `JPG`: 自动填充纯白底色（无黑边/无穿透）。
  - `WEBP`: 现代高压缩比，配备质量调节滑块。
  - `.SVG`: 一键导出原生矢量文件。

## 📦 组件架构

```
svg-to-image/
├── index.vue                          # 主工作台组件（整合工具栏与分栏）
├── composables/
│   └── useSvgConverter.js            # 转换状态与高分辨率离屏渲染 Composable
├── components/
│   ├── ResizableSplitter.vue          # 可拖拽比例分栏（支持左右/上下模式）
│   ├── SvgCodeEditor.vue              # CodeMirror 6 代码编辑组件
│   ├── SvgPreviewCanvas.vue           # 交互式平移缩放预览画布
│   ├── ExportPanel.vue                # 格式与倍率导出配置面板
│   └── FullscreenPreview.vue         # 沉浸大图全屏预览
├── utils/
│   └── svgUtils.js                    # 格式化、压缩、DOMParser 校验与预设示例库
└── README.md                          # 模块文档
```

## 🔒 隐私与安全性

- ✅ **纯前端本地处理**: 所有 SVG 解析、DOM 渲染与 Canvas 栅格化均在浏览器沙箱内完成。
- ✅ **零服务器上传**: 敏感矢量图形和数据绝不离机。
